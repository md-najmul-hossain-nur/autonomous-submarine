## 🌟 Features

- ✅ **Web Control**: Control from phone/laptop browser
- ✅ **Auto-Start**: Backend starts automatically on boot
- ✅ **WiFi Hotspot**: Connect directly to submarine
- ✅ **Object Detection**: AI finds objects underwater
- ✅ **Live Camera**: 1080p HD video streaming
- ✅ **Sensors**: Depth, temperature, orientation tracking
- ✅ **Auto Navigation**: Autonomous target following
